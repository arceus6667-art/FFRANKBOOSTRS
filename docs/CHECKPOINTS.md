## 2 — Identity persistence and API authorization foundation

Delivered:

- Supabase-compatible PostgreSQL migration for platform profiles, private game identities, consent versions, roles, eligibility and audit records.
- Row-level security on all six application tables with explicit grants. Player IDs and creation times cannot be overwritten by clients. Game UIDs remain owner-only, including against admin browser clients.
- Append-only client consent and read-only client role/eligibility records. Administrators cannot self-provision roles through the public API. A private, narrowly scoped role lookup supports admin reads without recursive policies.
- Request-scoped Supabase API client using publishable keys and bearer tokens; fresh Auth user verification, verified-email checks and database-backed admin permission checks. These helpers are ready to be used by future API routes; they are not deployed endpoints.
- PostgreSQL integration tests that execute the migration and test anonymous, owner, other-player and administrator access. Auth boundary tests cover forged metadata and failed permission lookups.
- Exact dependency versions and lockfile for repeatable installation.

Validation: `npm ci`, `npm test`, `npm run check`, and `npm audit`. Tests use embedded PostgreSQL (PGlite) with minimal Supabase Auth stubs. They do not simulate hosted GoTrue, PostgREST, email delivery, JWT expiry, or multiple simultaneous connections.

Not yet delivered: sign-up/sign-in/recovery screens, SSR cookies, auth callbacks, hosted auth configuration, tournament tables/transactions, teams, protected lobby access and result publication. No live schema has been changed and no hosted service has been purchased. Run Supabase advisors and repeat authorization tests against the actual staging project before launch.

The Supabase connector currently requires a connection identifier that is not provided in this chat. No live project was selected. Docker is installed but its engine is unavailable. These do not block local development; staging integration remains outstanding.
